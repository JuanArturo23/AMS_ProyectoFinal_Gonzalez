IA Responsable

Este repositorio contiene el desarrollo y la documentación de mi proyecto final para la materia de Análisis y Modelamiento de Software.

El proyecto consiste en una plataforma web pensada para AMS González S.A. de C.V. donde estudiantes y docentes pueden aprender a usar la Inteligencia Artificial generativa de forma responsable. En un mismo lugar se reúnen cursos cortos, consejos prácticos para redactar mejores prompts, las reglas básicas sobre ética, citación y cuidado de datos personales, y un asistente virtual que contesta dudas al momento.

Lo que se trabajó en cada fase

Fase I. Planeación de software: Revisamos qué problemas reales existen hoy cuando se usa la IA sin guía (como el plagio, compartir información privada en chats públicos o recibir respuestas inventadas por pedir mal las cosas). A partir de ahí definimos el objetivo SMART y el alcance del sistema.

Fase II. Análisis y modelamiento: Aplicamos cuestionarios, entrevistas y observación para sacar los requerimientos funcionales y no funcionales. Con esa base armamos los diagramas UML en PlantUML (diagrama de clases, casos de uso y diagrama de actividades).

Fase III. Diseño: Diseñamos en Balsamiq los bocetos de cada pantalla (inicio de sesión, lecciones, tips, normatividad y el chat del agente IA), además de definir las tecnologías web (HTML5, CSS3, JavaScript) y la base de datos en SQL.

Fase IV. Metodología SCRUM: Organizamos todo el avance en Jira Software dividido en 4 sprints con sus historias de usuario, tareas y corrección de errores, vinculándolo con este repositorio de GitHub.
